# פעמיים

אפליקציית **שניים מקרא ואחד תרגום** בעברית — React Native (Expo), Mobile-First, RTL מהיסוד.

## מה בפנים

- פרשת השבוע לפי לוח **ישראל / חו״ל**
- סיפור הפרשה + סיפור ההפטרה + **למה קוראים דווקא את ההפטרה הזו**
- קריאה מחולקת ל־ז׳ עליות (מסלול עד שבת)
- כרטיס פסוק: מקרא · מעבר א׳/ב׳ · אונקלוס · הסבר תרגום
- שתי תצוגות: פסוק־פסוק / גלילה רציפה (מגילה)
- מצב משפחה: אותו מסך, שני קולות
- מסך סיום: «סיימת שניים מקרא ואחד תרגום»
- נגישות מהיסוד (תוויות, roles, מגע מינימלי)
- עיצוב זכוכית iOS

## הרצה

```bash
npm install
npx expo start
```

אחר כך סרקו QR ב־Expo Go, או לחצו `w` לווב / `i` לסימולטור iOS / `a` לאנדרואיד.

## מבנה

```
app/           מסכים (expo-router)
src/components קומפוננטות זכוכית
src/data       פרשה, פסוקים, תרגום
src/store      התקדמות (Zustand + AsyncStorage)
src/theme      צבעים, רדיוסים, טיפוגרפיה
```

## נכסים חזותיים
